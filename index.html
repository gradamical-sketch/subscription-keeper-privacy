개인정보 처리방침

Effective date: 2026-09-29
Last updated: 2026-09-29

Subscription Keeper는 정기 구독의 비용·결제일·무료체험 종료일과 알림을 관리하는 Chrome 확장 프로그램입니다. 구독 정보는 기본적으로 사용자의 기기에 저장하며, 현재 실제 서비스 자동 해지나 결제 변경 기능은 제공하지 않습니다.

1. 처리 목적과 로컬 저장

구독 수동 관리, 결제 및 무료체험 종료 알림, 지원 사이트의 구독 후보 감지와 읽기 전용 상태 점검을 위해 다음 정보를 Chrome의 확장 프로그램 로컬 저장소에 보관합니다.

  • 서비스명, 금액, 통화, 월·연 결제 주기, 다음 결제일, 무료체험 종료일, 알림 설정
  • 선택적으로 입력한 메모와 직접 해지용 URL, 구독 상태와 갱신 여부, 이용 가능 기간
  • 감지하거나 저장한 후보의 서비스·플랜·가격·출처와 처리 상태
  • 제한된 구독 상태 점검 근거, 확인 시각, 단계 및 결과 기록
  • 화면·시작 안내 설정, 사이트 권한 상태 정보, 알림 발송 및 가져오기 처리 기록

구독 데이터의 자동 클라우드 동기화는 제공하지 않습니다. 로컬 저장소는 비밀번호용 암호화 금고가 아니므로 메모나 URL에 민감한 정보를 입력하지 마세요.

2. 수집하도록 설계하지 않은 정보

비밀번호, 카드번호, 금융기관 로그인 정보, 실제 결제 수단 정보, 쿠키·세션·인증 토큰을 수집하거나 저장하는 기능은 없습니다. 전체 브라우징 이력이나 전체 페이지 DOM을 저장하지 않습니다. 사용자가 자유 입력란에 직접 적은 내용은 입력한 그대로 로컬에 남을 수 있습니다.

3. 외부 전송과 분석 도구

현재 확장 프로그램에는 개발자 서버로 구독 데이터를 보내는 기능, analytics, telemetry 또는 원격 로그 전송 기능이 없습니다. 데이터를 판매하거나 광고 목적으로 외부에 제공하는 기능도 없습니다.

지원 사이트나 사용자가 지정한 해지 링크를 열면 브라우저가 해당 사이트에 정상 접속합니다. 해당 사이트의 데이터 처리는 그 사이트의 정책을 따릅니다. 이 정책 웹페이지에는 추적 스크립트, 외부 폰트, 분석 도구를 넣지 않았습니다. GitHub Pages로 게시될 경우 페이지 제공 과정의 접속 정보 처리는 GitHub의 개인정보 정책을 따릅니다.

4. 선택적 사이트 권한

  • GitHub: 공개 요금표에서 서비스·플랜·가격 등의 구독 후보를 감지합니다. 실제 계정의 가입 또는 유료 구독 상태를 확정하지 않습니다.
  • YouTube Premium: 사용자가 요청하면 구매·멤버십 페이지에서 제한된 구독 상태 근거를 읽기 전용으로 점검합니다. 실제 해지, 재가입 또는 결제 변경을 실행하지 않습니다. 계정 식별 정보로 해지 대상을 확정하는 기능은 지원하지 않습니다.

사이트 권한은 사용자가 선택하며 앱이나 Chrome 확장 관리 화면에서 해제할 수 있습니다. 해제 후에도 수동 구독 관리는 사용할 수 있습니다. 전체 사이트 접근 권한이나 전체 브라우징 이력 권한을 요구하지 않습니다.

5. 백업·가져오기·복구

사용자가 직접 JSON 파일을 내보내고 보관합니다. 파일에는 구독·후보의 식별자, 이름, 가격, 일정, 상태, 알림 선택과 시작 안내 설정이 포함될 수 있습니다. 이름과 금액도 개인 데이터일 수 있으므로 안전하게 보관하세요.

메모, 해지 URL, 사이트 권한, 검사 기록과 개발용 데이터는 백업에서 제외됩니다. 백업은 전체 저장소의 복제본이 아니며 사이트 권한이나 검사 기록을 복원하지 않습니다.

가져오기는 파일을 로컬에서 검증하고 미리보기 후 병합 또는 교체합니다. 확장이 파일을 서버에 업로드하지 않습니다. 적용 중 기존 사용자 데이터의 복구 사본을 일시적으로 로컬에 보관합니다. 성공 또는 복구 완료 후 삭제하며, 복구에 실패하면 데이터 보호를 위해 사본을 유지합니다. 마지막 가져오기 시각·방식·건수도 로컬에 기록합니다.

6. 문제 신고용 진단 정보

진단 복사에는 버전, 배포 채널, 브라우저 종류, 고정 서비스·Adapter 식별자, 지원 기능, 권한 여부, 점검 상태, 마지막 단계, 결과 코드(resultCode), 오류 코드(errorCode)와 시각 등 제한된 항목만 포함됩니다.

이메일, 계정 이름, 메모, URL, 인증 정보와 백업 내용은 진단 복사에서 제외합니다. 자동으로 전송하지 않으며 사용자가 내용을 확인한 후 직접 전달합니다. 지원 이메일로 직접 연락하면 사용자의 이메일 주소와 메시지 내용이 이메일 서비스 및 수신자에게 전달됩니다. 비밀번호·인증 정보·전체 백업 파일은 보내지 마세요.

7. 보관과 삭제

앱에서 개별 구독을 삭제하거나 ‘모든 구독 데이터 삭제’를 사용할 수 있습니다. 전체 삭제는 구독·후보·점검·알림 기록을 지우며 사이트 권한과 화면 설정은 유지합니다. 가져오기 처리 정보 등 일부 운영 설정은 남을 수 있습니다. 로컬 기록 삭제는 실제 서비스의 구독을 해지하지 않습니다.

완료된 점검 기록은 개수를 제한해 오래된 기록부터 정리합니다. 진행 중인 작업이나 복구 실패 사본은 보호를 위해 유지될 수 있습니다. Chrome에서 확장 프로그램을 제거하면 확장의 로컬 저장소가 삭제됩니다. 사용자가 다운로드하거나 다른 곳에 복사한 백업, 직접 보낸 이메일은 별도이며 확장 제거로 삭제되지 않습니다.
